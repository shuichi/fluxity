# 渋谷の戸口誘導の修正前後に各地点で入店・退出した人数と滞留人数

50店舗・全方向の街路端10か所、歩行者1,000人、メタAI無効で、自動信号・歩行速度設定1.35 m/s・回避強度1のまま18分29秒間を計測した。シードは42、歩行計算は毎秒30ステップ。開始時の1,000人について位置・個体属性・個々の目的地・目標座標・速度・体の向きのハッシュが修正前後で一致した。修正前のコードを保存して再計測し、既存の50店舗・全方向条件の全60地点と全指標の一致を確認した。[前回の4条件の比較](shibuya-destinations.md)

この比較の前に、青信号固定・シード467・メタAI無効で歩行者を1人だけ置いた。各目的地の到着レーンの1.65 m手前から60秒以内に入店・退出できた地点は、修正前が46/60（店舗36、街路端10）、修正後が60/60（店舗50、街路端10）だった。修正後に最も時間がかかった地点も6.43秒で完了した。地点別の完了ステップはJSONの `soloCompletionStep` に掲載した。

各セルは「修正前 → 修正後」。向かった人数は最初の1,000人と、観測中に新しく出現した歩行者の旅程を数えた。完了人数は店舗では入店、街路端では退出を完了した人数。

5分以上の滞留は、本人の目的地から12 m未満の歩道に1秒ごとの観測で連続300秒以上いた場合とした。店舗は戸口奥の終点、街路端は歩道側の入口を中心とする。累計は同じ旅程につき1回、終了時は18分29秒時点で条件を満たす人数を数えた。目的地に近づく途中、12 mの範囲外で待った時間は集計されない。

単独試験で以前通れなかった14店舗を合わせると、入店は31人から58人に増えた。これらの店で5分以上滞留した人数は累計32人から0人、終了時30人から0人に減った。一方、従来の北側街路端の退出は108人から22人、北西方面・東側歩道の退出は96人から63人に減った。北側街路端へ向かったのは154 → 159人で、出口付近で5分滞留した人数は両条件とも0人だった。観測範囲外での待ち時間の内訳は計測していない。

検討中には、店への最終進入路に入ると近隣の戸口の回避を一律に外す案も測定した。この案では入店227人、街路退出508人、5分以上滞留した累計22人、終了時17人だった。採用版は目的の入口への接近を妨げる誘導に限って抑える。以下の地点別表の修正後はすべて採用版の結果である。
